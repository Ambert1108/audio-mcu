## 创建任务

- describe：创建一个混音任务，用于接收多路音频流

- Url：`http://ip:port/audioMcu/create?jobId=xxx`

- Method:`post`

- Content-Type: `application/json`

- Param:

  - jobId:该字段为创建的混音任务id，需要保证全局唯一

- 请求参数

  | 参数名称     | 必选 | 参数类型 | 参数描述                            |
  | ------------ | ---- | -------- | ----------------------------------- |
  | codecType    | 是   | int      | 音频编码格式<br/>1：PCMA<br/>2：AAC |
  | sampleRate   | 否   | int      | 输出音频采样率                      |
  | aBitrate     | 否   | int      | 音频码率：仅在AMR编码格式下生效     |
  | timeInterval | 否   | int      | 时间间隔：仅在PCMA编码格式下生效    |
  
- 回复参数

  | 参数名称 | 参数类型 | 参数描述              |
  | -------- | -------- | --------------------- |
  | errCode  | int      | 错误码，为0时标识成功 |
  | msg      | string   | 响应信息，成功时为ok  |



## 添加通道

- describe：收到添加通道请求，创建并添加一个音频通道，设置通道为闭麦状态

- Url：`http://ip:port/audioMcu/add?channelId=xxx`

- Method:`post`

- Content-Type: `application/json`

- Param:

  - channelId:该字段为混音通道id，需要保证任务中唯一

- 请求参数

  | 参数名称   | 必选 | 参数类型 | 参数描述       |
  | ---------- | ---- | -------- | -------------- |
  | jobId      | 是   | string   | 任务id         |
  | sampleRate | 是   | int      | 输入音频采样率 |
  | dstIp      | 是   | string   | 目的ip         |
  | dstPort    | 是   | int      | 目的端口       |

- 回复参数

  | 参数名称 | 参数类型 | 参数描述              |
  | -------- | -------- | --------------------- |
  | errCode  | int      | 错误码，为0时标识成功 |
  | msg      | string   | 响应信息，成功时为ok  |
